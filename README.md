# JST BD Crockeries — জেএসটি বিডি ক্রোকারিজ 🍳

বাংলাদেশের কাস্টমারদের জন্য মোবাইল-ফার্স্ট, সম্পূর্ণ বাংলায় তৈরি ই-কমার্স ওয়েবসাইট (ফ্রন্টএন্ড ডেমো)। কোনো ব্যাকএন্ড / ডাটাবেস / পেইড টুল লাগে না — ১০০% ফ্রি-তে Vercel-এ ডেপ্লয় করা যায়।

🔗 **লাইভ ডেমো রেফারেন্স:** https://website-second-xi.vercel.app/

## ✨ ফিচার

- 🏠 হোমপেজ: হিরো, ক্যাটাগরি, আজকের ডিল + কাউন্টডাউন, ফিচার্ড পণ্য, রিভিউ, FAQ
- 🛍️ পণ্য পেজ: ক্যাটাগরি ফিল্টার, দাম/রেটিং/ছাড় অনুযায়ী সাজানো, সার্চ, স্টক ফিল্টার
- 📄 পণ্যের বিস্তারিত: ফটো গ্যালারি, পরিমাণ সিলেক্টর, স্পেসিফিকেশন টেবিল, রিভিউ
- 🛒 কার্ট: পরিমাণ বাড়ানো/কমানো, ডেলিভারি চার্জ হিসাব, ফ্রি-ডেলিভারি অফার
- 💬 হোয়াটসঅ্যাপ অর্ডার: কার্ট + কাস্টমার তথ্যসহ অর্ডার সরাসরি হোয়াটসঅ্যাপে যায়
- 🟢 ফ্লোটিং হোয়াটসঅ্যাপ "অর্ডার করুন" বাটন (সব পেজে)
- 👤 অ্যাকাউন্ট তৈরি / লগইন (ব্রাউজারে সংরক্ষিত — ডেমোর জন্য)
- 📱 মোবাইল বটম নেভিগেশন + সম্পূর্ণ রেসপন্সিভ ডিজাইন
- 🔢 সব দাম টাকায় (৳) ও বাংলা সংখ্যায়

## 🚀 Vercel-এ ডেপ্লয় (সম্পূর্ণ ফ্রি, কোডিং ছাড়াই)

এই রিপোজিটরি একটি **স্ট্যাটিক ওয়েবসাইট** (শুধু HTML/CSS/JS) — কোনো Build সেটিং লাগে না।

1. [vercel.com](https://vercel.com) → **Sign up** (GitHub দিয়ে, ফ্রি)
2. **Add New → Project → Import** এই GitHub রিপোজিটরি
3. Framework: **Other** (অটো-ডিটেক্ট হবে), Build Command খালি রাখুন
4. **Deploy** চাপুন — ১ মিনিটেই লাইভ লিংক পেয়ে যাবেন! 🎉

> কোনো Environment Variable, ডাটাবেস বা পেমেন্ট লাগে না।

## ⚙️ দোকানের তথ্য বদলানো (১ মিনিটে)

`assets/js/store.js` ফাইলের একদম উপরে `STORE` অংশে:

```js
whatsapp: "8801712345678",  // ← আপনার হোয়াটসঅ্যাপ নম্বর (88 সহ)
deliveryInside: 60,          // ঢাকার ভিতরে চার্জ
deliveryOutside: 120,        // ঢাকার বাইরে চার্জ
freeDeliveryOver: 5000,      // ফ্রি ডেলিভারির লিমিট
```

নতুন পণ্য যোগ করতে একই ফাইলের `PRODUCTS` লিস্টে আরেকটি পণ্য যোগ করুন — ছবি রাখুন `assets/img/` ফোল্ডারে।

## 📁 ফাইল গঠন

```
├── index.html            # হোমপেজ
├── products.html         # সব পণ্য
├── product.html          # পণ্যের বিস্তারিত (?id=...)
├── cart.html             # কার্ট + চেকআউট
├── account.html          # অ্যাকাউন্ট তৈরি / লগইন
├── vercel.json           # Vercel সেটিং (clean URLs)
└── assets/
    ├── css/style.css     # সম্পূর্ণ ডিজাইন
    ├── js/store.js       # পণ্য, কার্ট, অর্ডার — সব লজিক
    └── img/              # লোগো + পণ্যের ছবি
```

## 💻 লোকালি চালানো

```bash
cd JST-BD-Crockeries
python3 -m http.server 8000
# ব্রাউজারে খুলুন: http://localhost:8000
```
